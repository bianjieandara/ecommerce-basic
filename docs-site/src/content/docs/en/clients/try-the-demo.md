The demo store is a real store, with sample products, that anyone can try. You can buy, change prices, add products and open the
admin. Nothing charges money and no e-mail leaves the store.

**Where it is:** [ecommerce.relion-app.com](https://ecommerce.relion-app.com/en/). The admin sign-in is at
[ecommerce.relion-app.com/admin/login](https://ecommerce.relion-app.com/admin/login). The sign-in e-mail is
`demo@ecommerce.relion-app.com`; the password is shown on that same sign-in page.

:::caution[Everything resets every night]
At 03:00 (store time) the demo returns to its starting state. What you change, your orders and your products disappear. If you
want to leave something for someone, do it the same day.
:::

## Buy with a test payment

1. Add a product to the cart and go to checkout.
2. Choose **card**. On the dLocal Go page use `4111 1111 1111 1111`, any future date and any security code.
3. To pay with PayPal, use the sandbox buyer shown on the checkout page, if there is one. If none is shown, ask us for a login.
4. Afterwards open the order page. It shows the status and the e-mails the store would have sent: they open with the order link and
   never leave the demo.

## Walk through the admin

In the admin, the **Try this** card takes you through six tasks:

1. Mark an order as paid, then as shipped.
2. Issue an invoice for a paid order.
3. Change the colour in Settings > Theme and look at the shop.
4. Add a product with a picture.
5. Adjust the stock of a product.
6. Open a report and compare two periods.

The **Reset the demo now** button puts the store back to its starting state immediately.

## What the demo does not allow

The shared demo account cannot invite admins, change roles, deactivate users, reset its password or issue refunds. Those actions
show a demo message. Everything else is open.

## What is real

- The store, the admin, the cart and the test payment work as in a live store.
- Payments use the test environments of dLocal Go and PayPal, so nothing is charged.
- E-mails are kept, not sent. The site writes to no customer.
